## 已知登记照片问题

2026-10-24 诊断确认当前下载器未规范化中文 URL 路径，可能抛出 UnicodeEncodeError，随后向调用方返回通用“登记照片无法读取或解码”。2026-10-26 已修复：路径和查询按 UTF-8 百分号编码，下载、解码、人脸数量和质量失败在原有提示后追加具体原因，见[审核问题修复](review-fixes-20261026.md)。URL 编码后，还须验证照片地址对算法进程可访问；当前下载器不携带用户登录凭证。后端与算法需落实可下载地址或专用鉴权合同。

照片能够解码也不代表能通过质量检查。诊断样本被当前清晰度规则拒绝；2026-10-26 用公开样例复现的主要原因是小图放大或高分辨率轻微虚焦（BLURRED）、芯片照等小图人脸不足64像素（FACE_TOO_SMALL）及只裁脸部导致检测不到人脸，见同一文档；规则返回 thresholds_calibrated=false，不应未经样本标定直接改变生产阈值。原批次、照片、人员资料、服务器日志及凭证没有纳入本仓库。
